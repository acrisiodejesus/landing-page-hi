# Landing Page - Next.js

Uma landing page moderna e responsiva construída com Next.js, TypeScript e Tailwind CSS.

🌐 **Demonstração**: [https://landing-page-hi.vercel.app/](https://landing-page-hi.vercel.app/)

## Funcionalidades

- ✨ Design moderno e limpo
- 📱 Totalmente responsivo
- 🎨 Estilizado com Tailwind CSS
- 📝 Suporte a TypeScript
- 🔍 Otimizado para SEO
- 🚀 Alta performance
- 📱 Navegação otimizada para dispositivos móveis

## Tecnologias Utilizadas

- [React.js 19](https://react.dev/)
- [Next.js 14](https://nextjs.org/)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide Icons](https://lucide.dev/)

## Pré-requisitos

Antes de começar, certifique-se de ter instalado:

- Node.js (versão 18.17 ou superior)
- npm (geralmente vem com o Node.js)

## Como Executar o Projeto

1. Clone o repositório:

```bash
git clone https://github.com/seunome/landing-page.git
cd landing-page
```

2. Instale as dependências:

```bash
npm install
```

3. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

4. Acesse [http://localhost:3000](http://localhost:3000) no seu navegador para ver o resultado.

## Estrutura do Projeto

```
src/
  ├── app/
  │   ├── page.tsx        # Componente principal
  │   ├── layout.tsx      # Layout raiz
  │   └── globals.css     # Estilos globais
  └── components/
      ├── Navbar.tsx      # Componente de navegação
      ├── Hero.tsx        # Seção principal
      ├── Features.tsx    # Seção de funcionalidades
      ├── Pricing.tsx     # Seção de preços
      └── Footer.tsx      # Rodapé
```

## Comandos Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria uma build otimizada para produção
- `npm start` - Inicia o servidor de produção
- `npm run lint` - Executa o linter
- `npm run type-check` - Executa a verificação de tipos do TypeScript
